# ELI12: Speech Technology in plain language

**ELI12 = "explain it like I'm 12."** These five notes cover the same ideas as the weekly notes, but start from everyday pictures (flipbooks, trumpets, weather, autocomplete), use tiny numbers you can check by hand, and explain every symbol before using it. They are a gentle first pass, not a replacement for the full notes.

> [!TIP]
> **Suggested route.** Read the ELI12 note for the week, then the exam-focused guide, then try the past-paper questions. Every ELI12 note links to the exact questions it prepares you for.

## How to use Ask AI with these notes

Every heading has a small waveform button and the page has an **Ask AI** stamp. Select a sentence that still feels confusing, click the stamp, and the prompt asks for an even simpler explanation with a fresh example.

> [!NOTE]
> The ELI12 notes simplify the language, not the facts. Where a rule has a precise exam wording (for example, "greater than or equal to twice the maximum frequency"), the ELI12 note repeats it. Worked answers across the site are independently derived study aids, not official answer keys.
